# Code Review

Review code changes systematically for quality, security, and maintainability.

## When to Use

- Use when the user asks for a code review
- Use when reviewing pull requests
- Use when analyzing code quality

## Instructions

1. Review code structure and organization
2. Check correctness and edge cases
3. Check for security vulnerabilities (injection, auth, secrets)
4. Assess performance implications
5. Verify adherence to project conventions
6. Confirm tests cover the change
7. Suggest improvements with explanations
8. Highlight what is done well
9. Format feedback as Critical / Suggestion / Nice-to-have
